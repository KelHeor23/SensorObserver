◆ swapEndianness()

template<typename T >
T swapEndianness ( T  value)

Меняет порядок байт (эндивность) значения любого тривиального целочисленного типа.

Параметры шаблона
TЦелочисленный тип (например, uint16_t, uint32_t, uint64_t).
Аргументы
valueВходное значение в исходной эндивности.
Возвращает
Значение с обратным порядком байт.
Предупреждения
Шаблон рассчитан на целочисленные типы и не предназначен для float/double.
