Подробное описание

Сохранение и загрузка настроек сенсоров через QSettings.

Формирует путь к INI в каталоге приложения и предоставляет операции сохранения/загрузки всех сенсоров и отдельных элементов.

Возвращает путь к файлу настроек сенсоров.

Возвращает
Полный путь к INI-файлу (config/sensors.ini) в каталоге приложения.

Создаёт подкаталог config при необходимости и возвращает путь вида <каталог_приложения>/config/sensors.ini.
