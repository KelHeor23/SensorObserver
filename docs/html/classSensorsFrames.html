Подробное описание

Реестр реализованных фреймов и индекс по именам сенсоров.

Хранит объекты реализаций BaseProtocol для разных FrameTypes и поддерживает индексирование поля по имени сенсора для быстрого доступа из UI.

void SensorsFrames::rebuildIndex ( )

Перестраивает индекс сенсоров.

Проходит по всем фреймам и добавляет их поля в словарь быстрого доступа по имени сенсора. Используется после изменения набора фреймов или их полей.
